# HABIBI CLOTHING

**Desert Luxury · Street Royalty**  
Pretoria streetwear brand.

## Live site

https://diegothegammer.github.io/habibi-clothing/

## Pages

| Page | File |
|------|------|
| Home | `index.html` |
| Shop | `shop.html` |
| About | `about.html` |
| Contact | `contact.html` |
| Cart / Checkout | `cart.html`, `checkout.html` |
| Account | `login.html`, `signup.html`, `profile.html` |
| Admin | `admin.html` |

## Stack

- Static HTML/CSS/JS on GitHub Pages
- Firebase Auth + Realtime Database (products, orders, contact messages)
- Local cart (localStorage)

## Features

- Product catalogue with categories (Hats, T-Shirts, Hoodies, Pants)
- Featured products on home
- Cart + South Africa shipping (Gauteng R100 / other provinces R200)
- User accounts & order history
- Admin panel for products & orders
- Contact form

## Local development

Open any `.html` file in a browser, or serve the folder with a simple static server.
